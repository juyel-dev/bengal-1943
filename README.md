# বাংলা ১৯৪৩ (Bengal 1943)

A 2D time-travel survival game set in the 1943 Bengal famine. A modern student is stranded in the past and must reach Calcutta alive.

**Play:** https://juyel-dev.github.io/bengal-1943/

## Controls (keyboard + mouse)
A/D walk, Shift run, Space jump, S hide in bushes, E talk, J or click to strike.

## Status
Chapter 1 prototype: one village level with hunger and thirst, thieves, soldier patrols, and NPCs.

## Roadmap
1. Months 1-6: vertical slice, playtests with 20-30 people, devlog
2. Months 7-12: full Chapter 1, itch.io launch
3. Months 13-18: Chapter 2 (Calcutta), English subtitles, Steam page
4. Months 19-24: release

Built with plain HTML5 canvas. Open `index.html` to play locally.
